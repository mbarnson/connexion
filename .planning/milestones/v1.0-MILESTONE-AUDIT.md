## E2E Flows

### Flow 1: Spec Load → Validation → Response (13 steps)
1. YAML loaded → `Specification.from_dict()` detects version `(3, 1, 0)`
2. Routes to `OpenAPI31Specification`
3. Meta-schema validation via `Draft202012Validator`
4. `nullable: true` rejection (if present)
5. `_set_defaults()` initializes pathItems, paths
6. `resolve_refs()` preserves $ref siblings for 3.1
7. `OpenAPI31Operation.from_spec()` creates operations with `spec_version`
8. Request arrives → routing middleware matches path
9. `RequestValidationMiddleware` extracts `spec_version` from operation
10. `ParameterValidator` uses `Draft202012Validator` for 3.1
11. `JSONRequestBodyValidator` uses `Draft202012RequestValidator` for 3.1
12. Handler executes
13. `ResponseValidationMiddleware` uses `Draft202012ResponseValidator` for 3.1

**Status:** ✓ Complete, all steps verified
